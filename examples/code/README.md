# Examples

These examples contain code generated by OpenCLI along with minimal implementations required for the corresponding `ActionInterface`

To regenerate code you can run:

```sh
make gen-examples
```

You will see the examples for each supported framework:

#### Cobra (Go)

```sh
$ cd ./examples/code/cobra/pleasantries
$ GOWORK=off go run main.go --help
```

#### urfave/cli (Go)

```sh
$ cd ./examples/code/urfavecli/pleasantries
$ GOWORK=off go run main.go --help
```

#### Yargs (Typescript)

```sh
$ cd ./examples/code/yargs/pleasantries
$ npm i
$ npm run dev -- --help
```
